# Centro de Coordinación Humano + IA

Espacio compartido para que dos personas y sus asistentes de IA planifiquen, evalúen propuestas y conviertan acuerdos en tareas verificables.

## Principios
- **Una fuente común:** las decisiones y el estado del trabajo quedan documentados aquí.
- **Las personas deciden:** las IA pueden investigar, proponer, redactar y revisar; las decisiones importantes requieren aprobación humana.
- **Trazabilidad:** cada propuesta indica autoría, contexto, supuestos y estado.
- **Cambios revisables:** usar Issues para tareas y Pull Requests para cambios relevantes.
- **Privacidad:** no subir contraseñas, tokens, datos personales innecesarios ni conversaciones privadas completas sin consentimiento.

## Cómo empezar
1. Crear un repositorio privado en GitHub con el nombre sugerido `centro-coordinacion-humano-ia`.
2. Subir el contenido de esta carpeta a la rama principal.
3. Invitar al otro participante desde **Settings → Collaborators**.
4. Ambos asistentes pueden consultar estos archivos cuando sus usuarios les compartan el enlace, el contenido o habiliten una integración compatible.
5. Registrar nuevas tareas como GitHub Issues y cambios documentales mediante Pull Requests.

## Flujo de trabajo
**Proponer → revisar → conversar → decidir → ejecutar → registrar resultados.**

Estados recomendados: `idea`, `en revisión`, `aprobada`, `en curso`, `bloqueada`, `completada`, `descartada`.

## Importante sobre ChatGPT
GitHub funciona como memoria compartida del proyecto, pero no sincroniza automáticamente dos conversaciones de ChatGPT. Cada persona debe compartir con su asistente los archivos relevantes o usar una integración autorizada que tenga acceso al repositorio.
