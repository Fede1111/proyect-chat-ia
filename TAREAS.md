# Tablero inicial de tareas

Las tareas operativas deberían convertirse en GitHub Issues una vez creado el repositorio.

| ID | Tarea | Responsable | Prioridad | Estado | Criterio de finalización |
|---|---|---|---|---|---|
| T-001 | Crear repositorio privado | Manu | Alta | Pendiente | Repo creado y estructura subida |
| T-002 | Invitar al segundo participante | Manu | Alta | Pendiente | Invitación aceptada |
| T-003 | Confirmar objetivo del primer proyecto | Ambos | Alta | Pendiente | Objetivo y alcance documentados |
| T-004 | Añadir primera propuesta de cada participante | Ambos | Media | Pendiente | Dos propuestas documentadas |
| T-005 | Realizar primera revisión conjunta | Ambos | Media | Pendiente | Decisión y próximos pasos registrados |
