# Cómo contribuir

1. Para una idea nueva, abrir un Issue con la plantilla **Propuesta**.
2. Para una tarea concreta, abrir un Issue con la plantilla **Tarea**.
3. Para cambios relevantes en documentos, crear una rama y abrir un Pull Request.
4. Explicar el motivo, los supuestos, los riesgos y el resultado esperado.
5. Esperar revisión antes de incorporar decisiones importantes a `DECISIONES.md`.
6. No subir claves API, tokens, contraseñas, datos financieros privados ni historiales completos de chats.

## Convención de nombres
- Ramas: `propuesta/nombre-breve`, `docs/nombre-breve`, `tarea/nombre-breve`.
- Commits: mensajes breves y descriptivos, por ejemplo `docs: agregar primera propuesta`.
- Issues: `[PROPUESTA]`, `[TAREA]`, `[PREGUNTA]`, `[DECISIÓN]`.

## Uso de IA
Indicar qué asistente colaboró cuando sea útil. Revisar los resultados, verificar datos externos y no presentar una salida de IA como decisión aprobada por una persona.
